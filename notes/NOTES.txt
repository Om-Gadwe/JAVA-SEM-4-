Runtime polymorphism in Java is achieved through method overriding. In this program, the dog class overrides the eat() method of the animal class. When the method is called using a child class object, the JVM decides at runtime which method to execute based on the object type, hence demonstrating runtime polymorphism.

final Variables Definition:
A final variable is a constant whose value cannot be changed after initialization

final Methods Definition:
A final method cannot be overridden by a subclass

final Classes Definition:
A final class cannot be extended by any subclass

Abstract Keyword Definition:
The abstract keyword is used to define classes or methods that are incomplete and must be implemented by a subclass
Key Characteristics of Abstract Methods Points:
-Cannot be instantiated: Abstract methods exist only within abstract classes, which cannot be directly instantiated
-Must be overridden: Subclasses must implement all abstract methods unless they are also abstract classes
-Can coexist with concrete methods: Abstract classes can have both abstract and concrete methods
-Used for polymorphism: Provides a way to achieve runtime polymorphism

Interfaces in Java Definition:
An interface is a blueprint of a class that contains abstract methods
